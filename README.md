# GiftBTE
An efficient deterministic solver for phonon BTE

1. Input File Generator
Website: https://giftbteinput.netlify.app/
Purpose: This tool helps you generate the necessary input files for a Gift-BTE simulation.
Typical Use: You set up simulation parameters (such as material properties, temperature, boundary conditions, etc.) 
through its interface and then download the ready-to-use input files. 

2. Output Visualizer
Website: https://thermovisual.netlify.app/
Purpose: This tool helps you visualize the output results from a completed Gift-BTE simulation.
Typical Use: You upload the output files generated by the Gift-BTE solver, and the website creates interactive charts and graphs to help analyze temperature distribution.
